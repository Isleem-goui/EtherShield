## 1. Project Description

EtherShield is an educational cybersecurity project focused on Ethereum smart contract security. It aims to develop, test, audit and correct vulnerable Solidity smart contracts in a local Ethereum environment.

## 2. Project Objectives

- Understand Ethereum and EVM fundamentals.
- Develop vulnerable smart contracts.
- Identify and demonstrate security vulnerabilities.
- Perform security audits using Slither.
- Correct vulnerabilities and improve contract security.
- Create automated security tests.

## 3. Technologies Used

- Solidity
- Foundry
- Anvil
- Forge
- Slither
- OpenZeppelin
- Git and GitHub

## 4. Vulnerabilities Studied

- Reentrancy
- Access Control
- tx.origin
- Signature Replay
- Front-running / MEV
- Denial of Service

## 5. Project Modules

- M1: Ethereum Fundamentals
- M2: Vulnerable Smart Contracts
- M3: Exploitation Tests
- M4: Security Audit
- M5: Vulnerability Remediation
- M6: Final Report

## 6. Project Environment

All experiments are performed on a local Ethereum network using fictional accounts and funds.
